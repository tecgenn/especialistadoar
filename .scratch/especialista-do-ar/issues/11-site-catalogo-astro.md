# 11 — Site (catálogo Astro)

**What to build:** O catálogo público em Astro, consumindo a mesma base servida: páginas estáticas para os Aparelhos com Dados declarados, mais ilhas de interatividade para busca e filtro.

- A base é consumida numa cópia de build; o site não é a fonte da verdade.
- A interatividade reusa o módulo de consulta compartilhado.
- Conteúdo do site indexável (Pagefind fica para o conteúdo do site).

**Blocked by:** 10 — Documentação para agentes e teste de aceitação (portão). O portão precisa passar antes de investir no site.

**Status:** ready-for-agent
